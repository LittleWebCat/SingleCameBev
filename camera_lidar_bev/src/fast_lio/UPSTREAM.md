[Ericsii/FAST_LIO_ROS2](https://github.com/Ericsii/FAST_LIO_ROS2), branch `ros2`,
commit `2fffc570a25d0df172720bac034fbdb6a13d2162`.

The ikd-Tree source is the upstream submodule from
[hku-mars/ikd-Tree](https://github.com/hku-mars/ikd-Tree), commit
`e2e3f4e9d3b95a9e66b1ba83dc98d4a05ed8a3c4`.

Source copyright notices and the original GPL version 2 license are retained.
The upstream manifest's historical BSD label has been corrected to agree with
the repository LICENSE. Local integration changes are described in PORT_NOTES.md.
No nested Git repositories or runtime dependency downloads are required.
